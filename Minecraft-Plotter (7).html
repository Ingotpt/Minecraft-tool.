Triangulate (stronghold finder)
Java: throw an Eye of Ender and stand still, facing the way it flew. Press F3+C (this copies your position and direction), click the box below and press Ctrl+V. Repeat from a spot about 200 blocks away.
Bedrock can't show which way you face, so we use two spots instead:
  1. Note your X/Z, then throw an Eye of Ender.
  2. Walk the way it flew (throw again to stay on course). Note your X/Z where you stop.
  3. Do the same again from a spot about 200 blocks away.
The longer you follow it (50+ blocks), the more accurate it is.
Type the direction yourself, measured clockwise from north: N 0° · E 90° · S 180° · W 270°.

Console & Bedrock servers (PlayStation / Xbox / Switch)

Console players can't type in a server address by themselves. This trick adds a server list to the game so they can join any Bedrock server, including one that has your texture pack or add-on on it.

Easiest option — BedrockTogether (phone app, no DNS change)

A free third-party app that makes a server show up as a LAN game on your PlayStation or Xbox. Get it on Google Play (Android) or the App Store (iPhone).

  1. Connect the phone and the console to the same Wi‑Fi.
  2. On the phone, allow Local Network access when the app asks. In Minecraft, turn on Visible to LAN Players.
  3. In the app, type the server address and port, then tap Run.
  4. On the console, open the Friends tab → LAN and join the server that appears. You can close the app once you're in.

It joins Bedrock servers. Neither store page mentions Java servers, so a Java server probably needs Geyser (Part 1, step 3). It doesn't work with Realms, and it isn't made by Mojang. The Google Play page lists Switch as supported; the App Store page says it isn't.

Part 1 — Get a server (for the DNS method)

  1. Make a free Bedrock server at Aternos (or any Bedrock host).
  2. Add your pack: see Installing add-ons on Aternos (Bedrock). The server sends it to players when they join, so they don't install anything.
  3. Want a Java server instead? Geyser lets Bedrock players join it.
  4. Write down the server address and port (Bedrock is usually 19132).

Part 2 — Add the server list (BedrockConnect)

  1. Open the BedrockConnect page and copy the public DNS address it lists.
  2. Change your console's DNS to it (steps below).
  3. Start Minecraft → Servers tab → open any featured server. The BedrockConnect menu appears instead.
  4. Pick Connect to a Server, type your address and port, and join. It can remember servers for next time.
  5. When you're done, set DNS back to Automatic so everything else works normally.

Changing DNS on your console

  1. PlayStation: Settings → Network → Set Up Internet Connection → pick your connection → Custom → set DNS to Manual and enter the address as the Primary DNS (Secondary can be 8.8.8.8).
  2. Xbox: Settings → General → Network settings → Advanced settings → DNS settings → Manual.
  3. Switch: System Settings → Internet → Internet Settings → your network → Change Settings → DNS Settings → Manual.

Step-by-step with pictures: PlayStation guide · Xbox, PlayStation & Switch guide

Other option — a Realm (no DNS needed)

  1. Download a Bedrock add-on or texture pack (.mcaddon / .mcpack) from CurseForge (Bedrock), or buy one in the in-game Marketplace.
  2. On a PC or phone, open the file. Minecraft imports it by itself.
  3. Open your Realm's settings and add the pack under Resource Packs or Behavior Packs.
  4. Everyone who joins the Realm gets the pack. See how add-ons work on a Realm.

Realms only take Bedrock packs. Java mods won't work there.

The DNS address is run by someone else, so only use the one on the official BedrockConnect page. You can also run your own: Using your own DNS server.

Consoles only get what Bedrock supports: texture packs and Bedrock add-ons work, but Java mods don't.
